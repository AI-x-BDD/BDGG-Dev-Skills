### 第三題的自我檢查(題目引導的五個問題)

做完第二題後逐題回答,答得出「會」或「有」的地方就是改進點:

- [ ] **AI 還要自己猜嗎?** 只看 testplan.md,寫得出要測什麼、怎麼測、怎麼判定嗎?
- [ ] **換新對話還做得到嗎?** 只讀 workflow 的產出,新 session 能接手寫出原意的測試並繼續 TDD 嗎?
- [ ] **測試通過 = 功能做到了嗎?** 有沒有只檢查回應,沒確認資料或系統狀態?有沒有重要情境沒涵蓋?(Colab 題目特別相關:runtime 被收回、餘額歸零)
- [ ] **這次成功,有哪些是 AI 自己想到的?** 例如改功能時先改 testplan,這件事有寫進 Skill 嗎?
- [ ] **改進真的有幫助嗎?** 還是只是多了文件、重複別支 Skill 的工作?刪掉重複的也算改進
