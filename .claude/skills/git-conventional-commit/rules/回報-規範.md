# Rule 1 [must] - 與其他 skill 的回報合成一份
- 同一段工作裡還用了其他也要求回報的 skill 時,合成一份:同一件事只講一次
- 為什麼:每支 skill 各交一份,同一筆 commit、同一條 branch 會被講好幾次,使用者得自己比對哪幾段在講同一件事

## good example
- 同一段工作還用了要求回報分支狀態的 skill;**branch 只在一個地方講,兩支 skill 要的內容收在同一份**
```
## 提交結果

- 拆分:2 筆,修正與新功能互不相依
- branch:main(直接提交,未另開分支;已與 origin/main 同步)

| commit | header | 選這個 type 的理由 |
|---|---|---|
| 4f2a9c1 | `fix: return empty list when the data file is empty` | 修好既有的當掉行為 |
| 8b3d7e0 | `feat: add clear command` | 使用者拿到新指令 |
```

## bad example
- 同一段工作,但**兩支 skill 各交一份**;提交在哪條 branch 講了兩次,寫法還不一樣
```
## 提交結果

- 拆分:2 筆,修正與新功能互不相依
- branch:main

## 分支狀態

- 目前在 main,本次有 2 筆新的 commit 直接提交在 main 上,已與 origin/main 同步
```
