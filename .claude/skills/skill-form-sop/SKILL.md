# SOP

## Phase 1: 寫出 SOP
1. Read 目標 skill 已有的 SKILL.md。
2. Write 依 `rules/SOP-格式規範.md` 把使用者要的流程寫成目標 skill 的 `# SOP`。

## Phase 2: 列出把關紀錄
1. Read 剛寫進目標 skill 的 `# SOP`。
2. Think 依 `rules/把關紀錄-格式規範.md` 列出把關紀錄;若有 must 不過 → 跳至 Phase 1 Step 2。
