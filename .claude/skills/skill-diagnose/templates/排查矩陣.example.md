# 排查矩陣: skill-engineering

- 待排查現象: H4 實跑中受測 agent 讀過模板、拿到實跑結果，最後卻宣稱 Step 4 已完成且未交六欄表
- 要你回答: 優先驗證哪一個可疑原因;或指定其他要驗證的假說

## 可疑原因

| 可疑原因 | 支持線索 | 尚不能確定的地方 |
|---|---|---|
| 把「驗收通過」當成「驗收紀錄已完成」 | 診斷宣稱 Step 4 完成，最後只說實跑通過 | 無法直接知道 agent 當時怎麼判斷 |
| 提早讀模板，實跑後沒有重新套用 | 模板在第二層實跑前讀取，之後沒有重讀 | 沒重讀不必然會漏表 |
| Think 動詞讓它偏向內部判斷，忽略交付動作 | Step 4 以 Think 開頭且行尾綁定判定跳轉 | 同一句已明寫「在給使用者的回覆裡列出」 |

## 已排除或已有反證的原因

| 原因 | 排除依據 |
|---|---|
| SOP 沒要求交紀錄 | Phase 5 Step 4 明確要求 |
| SOP 沒連到模板 | 該步直接點名骨架與範例 |
| 模板不存在、路徑錯誤或讀取失敗 | 事件日誌記錄成功讀取 |
| 表格只是放錯段落 | 最後回覆與診斷檔都沒有表 |
| agy 中途失敗，來不及回覆 | 執行成功結束，有完整最後回覆 |
