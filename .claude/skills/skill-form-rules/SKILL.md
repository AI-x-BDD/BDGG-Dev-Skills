# SOP

## Phase 1: 寫出 Rule File
1. Read 目標 skill 的 SKILL.md 與已有的 Rule File。
2. Write 依 `rules/RuleFile-格式規範.md` 把使用者要的規則寫成目標 skill `rules/` 底下的 Rule File。
3. Think 逐條對照;若有不過 → 跳至 Phase 1 Step 2。
