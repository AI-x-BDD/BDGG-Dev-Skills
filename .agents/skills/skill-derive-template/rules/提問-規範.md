# Rule 1 [must] - 提問時列出每一步與它已有的樣板
- 問之前先用一張表列出目標 skill 的每一步:步驟位址、那一行的原文、那一行點名的樣板(沒有就寫「沒有」)
- 為什麼:只問「要抽哪一步」,使用者答不出來;看到每一步的原文與已經有的樣板,才指得出哪一步生成的內容還沒有固定的樣子

## good example
- **先列出五步的原文與各自的樣板,再問**;使用者一眼看得出 Phase 1 Step 3 會生成一張圖,卻還沒有樣板
```
| 步驟 | 原文 | 點名的樣板 |
|---|---|---|
| Phase 1 Step 1 | Read 這次開發會動到的現有程式碼。 | 沒有 |
| Phase 1 Step 2 | Think 依 `rules/類別圖-規範.md` 設計這次開發的類別組織。 | 沒有 |
| Phase 1 Step 3 | Ask 依 `rules/確認-規範.md` 用 Mermaid `classDiagram` 提出這份設計,問使用者是否可以進入開發;若使用者要修改 → 跳至 Phase 1 Step 2。 | 沒有 |
| Phase 2 Step 1 | Think 依 `rules/實作-規範.md` 排出類別的開發順序。 | 沒有 |
| Phase 2 Step 2 | Write 依 `rules/實作-偏離-規範.md` 照這個順序逐一實作類別圖裡的類別;若必須偏離類別圖 → 跳至 Phase 1 Step 2。 | 沒有 |

要抽哪一步?那一步生成的內容要長什麼樣子?
```

## bad example
- 同一次提問,但**只丟出問題**;使用者得自己去翻 SKILL.md 和 `templates/`,才知道有哪幾步、哪幾步已經有樣板
```
要抽哪一步(Phase N Step M)?那一步生成的內容要長什麼樣子?
```
