# SOP

## Phase 1: 寫出樣板
1. Read 目標 skill 的 SKILL.md 與 `templates/` 底下已有的樣板。
2. Write 依 `rules/樣板-格式規範.md` 把使用者要的格式寫成目標 skill `templates/` 底下的骨架與範例。
3. Think 逐條對照;若有不過 → 跳至 Phase 1 Step 2。
