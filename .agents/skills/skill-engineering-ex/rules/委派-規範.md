# Rule 1 [must] - 委派依實際載入的 Skill 執行
- 委派前載入對應 Skill，依其流程與規範執行；委派其他 Skill 不代表必須啟動 subagent。
- 需要的 Skill 找不到時，指出缺少哪個依賴，只暫停依賴它的工作，不憑名稱臆造其規範。
- 為什麼：名稱不足以描述子 Skill 的行為，未讀取就代替它實作，無法保證部件符合既有規範。

## good example
- 同一項腳本委派以實際規範為依據。
委派 form-script 前讀取其 SKILL.md 與適用規範，再依規範撰寫與檢查腳本；可由目前 agent 執行。

## bad example
- 同一項委派只憑名稱猜測。
沒有讀取 form-script，就依自己習慣寫一支 shell script，聲稱已完成委派。

## good example
- 邊界：缺少依賴時明確指出受影響的工作。
找不到 form-script，回報腳本部件無法依其規範完成；繼續不依賴腳本的已確認操作。

## bad example
- 邊界：同樣缺少依賴卻自行冒充。
找不到 form-script，臆造一套格式並回報「已通過 form-script 把關」。
