# Rule 1 [must] - 憲法的條文和本 Skill 的規範都要照做
- 寫 testplan.md 時,`constitution_rules.py` 交回的每一條條文都照做;本 Skill 的規範沒有被條文點名取代的,也照樣照做
- 條文和本 Skill 的規範要求的是不同的事時,兩邊同時成立,不因為有了憲法就跳過本 Skill 的規範
- 為什麼:憲法是這個專案多加的要求,Skill 的規範是測試計劃能被 `/tasks` 與 `/tdd` 讀懂的基本盤;只照其中一邊,交出的 testplan.md 不是違反憲法,就是讓下游讀不懂

## good example
- 憲法要一律用繁體中文與台灣用語,Skill 要「則」只斷言一件事;**兩邊都照做**
```
憲法:constitution/_shared/語言.md〈一律使用繁體中文與台灣用語〉
Skill:rules/測試案例-規範.md〈一條則只斷言一件可以觀察的事〉

| US1-LIB-03 | `ModelLibrary` › `search` | … | 則1:回傳 3 個名稱<br>則2:`has_more` 為 true | 社群模型混進結果 | FR-020 |
```

## bad example
- 同一個案例,用詞照了憲法,但**一條則塞了兩件事**;只照了憲法,`/tdd` 紅燈時分不出是哪一件沒做到
```
| US1-LIB-03 | `ModelLibrary` › `search` | … | 則1:回傳 3 個名稱而且 `has_more` 為 true | 社群模型混進結果 | FR-020 |
```

## good example
- 邊界:這個專案沒有任何套用到 testplan 的條文(`constitution_rules.py` 交回空的);**照本 Skill 的規範寫**,提出測試計劃時寫明「沒有套用的憲法條文」
```
憲法對照:沒有套用到 testplan/testplan 的條文
```

## bad example
- 邊界:同一個情況,**跳過對照,也沒有在提出時說明**;使用者分不出是沒有條文,還是沒有對照過
```
(提出測試計劃,沒有提到憲法)
```

# Rule 2 [must] - 沒有點名取代的衝突照本 Skill 的 Rule 做並交給使用者決定
- 條文和本 Skill 的某條 Rule 衝突、卻沒有用 `- 取代:` 點名它時,不自己選邊:testplan.md 照本 Skill 的 Rule 寫,把衝突的條文與 Rule 列進提出測試計劃時的問題,由使用者決定要改憲法還是改產出物
- 為什麼:沒有點名的衝突,使用者沒有決定過要翻掉哪一條;AI 自己選了憲法,等於替使用者改了 Skill 的規範,選了 Skill 又沒說,使用者以為憲法有被照做

## good example
- 條文要「每個案例都接真的服務」,但沒有點名取代〈每個替身至少有一個不用它的實跑案例〉;**照 Skill 寫替身與實跑案例,把衝突列進提出時的問題**
```
憲法:constitution/testplan/testplan.md〈每個案例都接真的服務〉(沒有取代)
Skill:rules/待測端點-規範.md〈每個替身至少有一個不用它的實跑案例〉
提出測試計劃時的問題:這條憲法要每個案例都接真服務,和 Skill 用替身加實跑案例的做法衝突;要改憲法,還是照憲法改成全部接真服務?
```

## bad example
- 同一個衝突,**自己照憲法把所有替身拿掉**,也沒有說明;每個案例都打真的 Colab,跑一次就要花 compute units
```
(待測端點表的替身欄全部寫「無」,沒有提到憲法衝突)
```
